# SentientArchive User Guide

Client-facing flows for the SentientArchive web app.

## Getting started

1. Open the landing page and choose **Get Started** or **Log In**.
2. Create an account with email/password or Google.
3. After sign-in you land on the **Dashboard**.

## Notes

1. Open **Notes** from the sidebar.
2. Create a note or upload a PDF/TXT/MD file to extract text.
3. Organize notes with folders and tags; use search and sort to find items.
4. Open a note to read or edit markdown with live preview.

## AI features

From a note, open the AI assistant to:

- **Summarize** the note (uses tokens)
- **Auto-tag** the note
- **Generate flashcards**
- **Ask questions** about your knowledge base (Q&A)

Token costs are shown on the landing page Token System section and in the app.

## Tokens

1. Open **Tokens** to view balance and transaction history.
2. Request more tokens when your balance is low (admin approval).
3. Dashboard warns when balance is below the low threshold.

## Activity

Open **Activity** for a timeline of your AI, token, note, and folder actions. Filter by
category or search the log.

## Settings

1. Open **Settings**.
2. Update your display name and save.
3. Email (username) is read-only.
4. Change language with the language switcher in the sidebar (en / es / fr / pt).

## Language

Use the flag/language control in the public navbar or dashboard sidebar. When signed in,
preference is persisted to your profile.
